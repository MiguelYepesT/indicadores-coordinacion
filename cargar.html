Cargar datos del mes

Elige el mes, adjunta los archivos y publica. El tablero se actualiza solo.

1Entra con la contraseña de actualización

Funciona desde cualquier computador. Es distinta del PIN que se usa para ver el tablero. Sesión abierta en esta pestaña.

2¿Qué mes vas a cargar o reemplazar?

3Adjunta los archivos

Puedes adjuntar uno, dos o los tres. Lo que no adjuntes se queda como está publicado.

Excel de ingresos y retiros del mes El archivo mensual de la subcarpeta (hoja INGRESOS).
Consolidado de retiros INFO RETIROS INDICADOR, la versión más reciente. Reemplaza los retiros de todos los meses que traiga.
Total de empleados TOTAL EMPLEADOS, con el bloque del mes. Se usa para el índice de rotación.

4Revisa y publica

Así quedan los meses que cambian. Los demás meses no se tocan.

    Administrador: configurar el acceso

    Se hace una vez, o cuando cambie el token, el PIN o la contraseña de actualización. Guarda en el repositorio el token y el PIN cifrados con la contraseña de actualización (archivo acceso.json).

    Recomendado: al menos 12 caracteres y distinta del PIN. Quien la tenga puede modificar el repositorio.

    Los Excel no salen de este computador. Se leen dentro del navegador; a GitHub solo se envía el resultado cifrado con el PIN, que contiene conteos por mes y empresa, sin nombres ni documentos.
